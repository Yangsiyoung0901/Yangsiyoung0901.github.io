# 양시영 | Simulation & Robotics Portfolio

공개 포트폴리오: https://yangsiyoung0901.github.io/

Unreal Engine·Isaac Sim·ROS 2·STM32·PLC 프로젝트를 소개하는 정적 웹 포트폴리오입니다.

## 구성

- `index.html`: 소개, 경력, 스마트팜 상세 사례, 프로젝트 카드
- `styles.css`: 반응형 화면 스타일
- `app.js`: 탭, 이미지 확대, 지도 경로 전환
- `project-details.js`: 프로젝트별 상세 내용
- `capture-viewer.js`: 주행 기록 캡처와 영상 보기
- `assets/`: 이미지, 지도, 주행 기록 MP4
- `.nojekyll`: 정적 파일 그대로 배포

## 배포

GitHub Pages가 `master` 브랜치의 루트에서 배포합니다. 별도 빌드나 로그인은 필요하지 않습니다.

2026-10-30에 공개 웹 포트폴리오를 이전했습니다. 이전 사이트는 Git 이력에 보존되며, 기존 템플릿의 파일과 라이선스도 유지합니다.

## 자료 해석

주행 비교 화면과 영상은 저장된 로그의 RViz 재생 자료입니다. 시험 날짜와 실측·추정·이론값 구분은 본문에 표시합니다.
